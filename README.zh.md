# 秀墨启动器

[English](./README.md) | **简体中文**

## 简介
秀墨启动器是一个为运行Android操作系统的电纸书阅读器设计的桌面应用程序。它的名字来源于拉丁语sumere，意为“拿”，引申为“获取”，对应于阅读的目的：获取知识。

## 核心功能
此应用力图在满足基础需求的同时尽可能提升流畅度。
1. 针对电纸书普遍存在的性能问题，此应用使用ViewPager2而非传统的GridLayout实现应用程序页面。它具有垃圾回收功能，对于安装了较多应用、需要多个页面显示应用程序的设备，能够自动回收暂时不需要的页面，保证流畅性和较低的内存占用。
2. 部分电纸书具有翻页按键。此应用已针对这些设备进行优化，意味着您可以通过这些按键翻页。
3. 对于部分设备将status_bar_height设为0、导致状态栏被隐藏的问题，此应用提供了一个简单的模拟状态栏。您可以查看时间、日期、铃声模式、飞行模式、WiFi、蓝牙和电池的状态。
4. 对于部分设备隐藏系统设置应用的问题，此应用提供了一个简单的控制中心。您可以打开WiFi、蓝牙、声音和显示等常用设置，也可以通过激活设备管理器实现一键锁屏。

## 快速上手
### 系统要求
推荐系统版本：Android 11 (API 30) 及以上，armeabi-v7a（32位）和arm64-v8a（64位）
最低系统版本：Android 6.0 (API 23) 及以上，armeabi-v7a（32位）和arm64-v8a（64位）
### 安装指南
1. 在页面右侧Releases中点击最新版本，打开版本详情页面；
2. 下滑，找到Assets中的Sume_Launcher_<版本号>_all.apk，点击下载；
3. 在设备上启用“安装未知来源的应用”功能；
4. 将安装包导入设备，点击安装。
